# KAKEIBO BUDGETING PLAN

I want to make a Kakeibo Budgeting app that runs on mobile and desktop. I want to start to work with web-based first, and port it as desktop app (electron maybe) and mobile app (need recommendation for framework) or use something like code once build for all platform framework like tauri or recommend me.

The app should be simple and easy to use, especially when inputting in/out purchase. My idea is to input it as chat base interaction and let the ai decide the categories, amount, label, etc.

For the frontend I want to use react and tailwindcss, and for the backend I want to use node + hono. I want the app has sleek ui with gradient and modern minimal look so user won't overwhelming with inputting the purchase.

For the LLM, I want to use free model so I can keep zero on budget. Recommend me with free LLM that can handle the task.

I also want to deploy it on my vps with Coolify deployment so maybe I need docker compose setup as well.
